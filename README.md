# ⚔️ Cinder Gauntlet — Boss Rush

Cinder Gauntlet is a high-intensity, 3D boss-rush experience built with Three.js. Face off against menacing entities in a series of challenging encounters, testing your reflexes and strategy.

## 🚀 Features
- **Epic Boss Battles**: Dynamic encounters with unique attack patterns.
- **Professional 3D Pipeline**: Powered by Three.js with a GLTF-ready asset pipeline.
- **Atmospheric Visuals**: Cinematic lighting, bloom effects, and immersive environments.
- **Responsive Design**: Playable across various screen sizes.

## 🛠️ Installation & Setup
Since this is a web-based game, you can run it locally or host it on GitHub Pages.

### Local Play
1. Clone the repository:
   ```bash
   git clone https://github.com/sifrex19-blip/CinderGauntlet.git
   ```
2. Open `index.html` in any modern web browser.

### Hosting on GitHub Pages
1. Go to **Settings** > **Pages** in your GitHub repository.
2. Select the `main` branch as the source.
3. Click **Save**. Your game will be live at `https://sifrex19-blip.github.io/CinderGauntlet/`.

## 📁 Project Structure
- `index.html`: The main game entry point.
- `/assets/models`: Contains 3D boss and environment models.
- `/assets/textures`: High-resolution textures and environment maps.
- `/assets/sounds`: Immersive audio and music.
